# Financial-Wallet-Project
Create a Digital Wallet for my personal needs. But i think it's okay to share it. Just for fun and experimental

## Dompet Ivan v5.0

A personal wallet app for Android ("Dompet" means "wallet" in Indonesian). It works fully offline: no account, no ads, no internet permission. The app's interface is in Indonesian.

- Ready-to-install APK: [`releases/Dompet_Ivan_v5.0.1.apk`](https://github.com/IvanLuga/Financial-Wallet-Project/raw/main/releases/Dompet_Ivan_v5.0.1.apk) (5.0.1 = 5.0 with the new app icon). It installs as an update over Dompet Ivan 4.0 and Dompet 3.x (same signing certificate, existing data is kept). The previous version stays available in [`releases/`](releases/).
- Source code, release notes, build steps, and testing: [`Dompet_Ivan_Project/README.md`](Dompet_Ivan_Project/README.md).

New in 5.0: months that start on your payday, a "safe to spend today" amount that accounts for upcoming bills and goals, a personal spending-pace curve, goals linked to accounts, envelope rollover, transaction suggestions from bank/e-wallet notifications, a home-screen widget with one-tap recording, bank-statement CSV import, password-protected automatic backups, personal inflation, a subscription audit, and weekly/monthly reports.

In 4.0: a financial reset with safeguards, currency switching, a transaction trash bin, weekly-to-yearly bills, and fingerprint unlock.
